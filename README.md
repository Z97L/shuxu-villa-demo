# Shuxu Villa Design Demo

Static interactive frontend preview with illustrative building parameters, floor plans and customer records.
Open the published GitHub Pages URL in a modern desktop or mobile browser.
All edits stay in the visitor browser. No login, payment, backend submission or shared customer database is connected.

Images are reference frames from a supplied video. They are not verified built projects or construction documents.
This repository contains the compiled preview assets only.
Third-party software notices are in licenses/; the Noto Sans SC font license is in fonts/OFL.txt.
